# coo-short-video-cdn

Public HTTPS hosting for COO short-video assets (Buffer / Instagram / YouTube).

## How to use
1. Create a [Release](https://github.com/sunlin-xiaonai/coo-short-video-cdn/releases) tagged like `short-video-YYYY-MM-DD`.
2. Attach `.mp4` (and optional images) as release assets.
3. Use each asset's download URL in Buffer (stable public HTTPS).
